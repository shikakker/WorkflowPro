# WorkflowPro

Dashboard prototype for monitoring automation workflows and connected services.

## Features

- High-level workflow statistics.
- Recent workflow list and status tracking.
- Active, paused, and error workflow states.
- Integration overview for services such as Make, n8n, and Google Calendar.
- Entry point for creating a new workflow.

## Tech stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start Vite.
- `npm run build` — create a production build.
- `npm run lint` — run ESLint.
- `npm run preview` — preview the build.

## Status

Front-end product prototype. Workflow execution and external-service authentication are represented in the UI but require backend integrations for production use.
